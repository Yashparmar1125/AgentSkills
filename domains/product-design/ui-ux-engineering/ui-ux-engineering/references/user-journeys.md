# User Journeys & Experience Mapping Guide

## 1. Journey Stage Structure
```text
Awareness / Need → Entry Point → Exploration / Input → Decision / Action → Confirmation → Retention / Return
```

## 2. Emotional Curve & Friction Points
- Map emotional confidence (Excited $\rightarrow$ Overwhelmed $\rightarrow$ Relieved $\rightarrow$ Accomplished).
- Identify high-friction transition points (e.g., entering credit card, uploading 50 questions, submitting final exam).
- Provide supportive UX at anxiety peaks (e.g., "All answers auto-saved", clear countdown timers).
