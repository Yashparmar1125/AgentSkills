# User Personas & Mental Models Guide

## 1. Persona Dimensions
- **Role & Context**: e.g., "Exam Administrator", "Classroom Teacher", "Distracted Student".
- **Primary Goals**: High-frequency workflows they must complete quickly.
- **Frustrations & Stressors**: Slow load times, data loss fears, dense unsearchable tables.
- **Technical Literacy**: Power user needing keyboard shortcuts vs. casual user needing guided wizards.

## 2. Mental Models & Expectation Mapping
Match system metaphors to real-world expectations:
- An "Exam Pack" should behave like a folder or curriculum bundle.
- A "Draft" should save automatically and never block tab navigation.
