# Information Architecture & Navigation Systems Guide

## 1. Hierarchy Models
- **Strict Hierarchy (Tree)**: Clear root $\rightarrow$ categories $\rightarrow$ subcategories (ideal for enterprise admin panels).
- **Hub and Spoke**: Central dashboard navigating outward to discrete tools (ideal for student portal).
- **Linear Workflow**: Step 1 $\rightarrow$ Step 2 $\rightarrow$ Step 3 (ideal for exam creation and checkout).

## 2. Navigation Patterns
- **Primary Desktop Nav**: Persistent collapsible sidebar with active indicator and badge counters.
- **Mobile Nav**: Bottom tab bar (3-5 items) or slide-over drawer with touch-friendly tap targets.
- **Wayfinding**: Contextual breadcrumbs (`Dashboard > JLPT N5 > Results`) to prevent disorientation.
