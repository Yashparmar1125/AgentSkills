# Typography & Typographic Scale Guide

## 1. Modular Type Scale
| Level | Font Size | Line Height | Font Weight | Tailwind Class | Typical Usage |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Display** | 36px - 48px | 1.1 - 1.2 | 800 (Extrabold) | `text-4xl sm:text-5xl font-black` | Hero headings, Landing pages |
| **H1** | 30px - 36px | 1.2 | 800 (Bold) | `text-3xl font-extrabold` | Top-level page titles |
| **H2** | 24px - 28px | 1.25 | 700 (Bold) | `text-2xl font-bold` | Section headers, card titles |
| **H3** | 18px - 20px | 1.3 | 600 (Semibold) | `text-lg sm:text-xl font-semibold` | Subsections, modal titles |
| **Body Large**| 16px | 1.5 | 400-500 | `text-base` | Lead paragraphs, exam prompts |
| **Body** | 14px | 1.5 | 400-500 | `text-sm` | Default table/form copy |
| **Caption** | 12px | 1.4 | 500-600 | `text-xs` | Metadata, badge labels, hints |
| **Micro** | 10px - 11px | 1.3 | 600 (Medium) | `text-[10px] sm:text-xs` | Pill indicators, keyboard keys |
