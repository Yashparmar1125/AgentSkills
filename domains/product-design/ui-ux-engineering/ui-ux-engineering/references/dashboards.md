# Dashboards & Analytical UX Guide

## 1. Executive Dashboard Architecture
```text
[Top Navigation & Global Filter Bar (Date, Cohort, Batch)]
                         ↓
[Executive KPI Ribbon (4-5 Hero Metrics with Trends)]
                         ↓
[Primary Visualization Grid (Charts, Trajectories, Distributions)]
                         ↓
[Actionable Breakdown Table (At-Risk Roster, Recent Activity)]
```

## 2. Preventing Visual Clutter & Cognitive Overload
- Cap top-level KPI cards at 4-5 items.
- Provide progressive disclosure: display summary metrics first with a drill-down modal or slide-over drawer for granular telemetry.
