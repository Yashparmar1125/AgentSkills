# Color Systems & Semantic Palette Guide

## 1. Palette Architecture
- **Primary Brand**: e.g., Indigo (`#4f46e5` - `indigo-600`) / Blue (`#2563eb` - `blue-600`).
- **Neutral Surface**: Slate / Neutral scale (`slate-50` background, `white` card, `slate-200` border, `slate-900` text).
- **Semantic Colors**:
  - **Success / Healthy**: Emerald / Green (`emerald-600`, bg `emerald-50`, border `emerald-200`).
  - **Warning / Watch**: Amber / Yellow (`amber-600`, bg `amber-50`, border `amber-200`).
  - **Danger / Critical**: Rose / Red (`rose-600`, bg `rose-50`, border `rose-200`).
  - **Information / Notice**: Sky / Blue (`sky-600`, bg `sky-50`, border `sky-200`).

## 2. WCAG Contrast Verification
- Normal Text (< 18pt): Minimum **4.5:1** contrast ratio against background.
- Large Text ($\ge$ 18pt or 14pt bold): Minimum **3.0:1** contrast ratio.
- UI Components & Focus Rings: Minimum **3.0:1** contrast ratio against adjacent surfaces.
