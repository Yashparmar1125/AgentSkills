# Mobile UX & Touch Interaction Guide

## 1. Ergonomic Thumb Zones
- Place primary interactive triggers (submit buttons, navigation tabs, bottom sheets) within the lower 40% of the viewport.
- Place destructive or rarely used actions in the top-right or secondary overflow menus to prevent accidental taps.

## 2. Touch Target Padding
- Use Tailwind utility classes like `p-2.5 sm:p-2` or `min-h-[44px]` to guarantee touch accessibility on smaller physical screens.
