# UX Research Methodology Guide

## 1. Quantitative vs. Qualitative Research in AI-Assisted Design
- **Qualitative**: Direct user observation, task completion walkthroughs, interview transcripts, and friction logs.
- **Quantitative**: Telemetry metrics (time on page, drop-off rates, error frequencies, heatmaps, bounce rates).

## 2. Problem Framing Framework
1. **Current State & Pain Points**: What friction exists in the current flow?
2. **User Goal**: What is the user trying to achieve?
3. **Business Goal**: How does solving this create business value?
4. **Hypothesis**: "If we [introduce X pattern], then [Y outcome] will improve because [Z cognitive reason]."
