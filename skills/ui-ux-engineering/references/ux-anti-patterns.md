# UX Anti-Patterns & Dark Patterns to Avoid

## 1. Critical UX Anti-Patterns
- **Mystery Meat Navigation**: Icons without text labels or tooltips that force users to guess functionality.
- **Infinite Spinners**: Loading spinners that run indefinitely when an API request fails quietly.
- **Modal Inception**: Opening a modal dialog on top of another modal dialog.
- **Layout Shift / Content Jump**: Elements popping in dynamically and shifting existing buttons while the user is clicking.
- **Silent Save Failures**: Forms that close without notifying the user that data was not saved.
- **Hard-to-Hit Touch Targets**: Tiny 16px icon buttons on mobile viewports.
