# Visual Design & Hierarchy Principles Guide

## 1. The 4 Levels of Visual Weight
1. **Dominant (Primary)**: Key action buttons, active tab, primary KPI number (`text-3xl font-extrabold text-slate-900`).
2. **Subordinate (Secondary)**: Section headers, secondary buttons (`text-lg font-bold text-slate-700`).
3. **Supporting (Body)**: Form labels, table cell content, descriptions (`text-sm font-medium text-slate-600`).
4. **Subdued (Metadata)**: Timestamps, hints, badges, auxiliary IDs (`text-xs font-normal text-slate-400`).

## 2. Intentional Contrast & Density
- High density for expert power-tools (e.g., student roster tables, code editors).
- Low density / generous whitespace for high-stress, focused workflows (e.g., exam-taking screen).
