# User Onboarding & First-Run Experience Guide

## 1. The 3 Onboarding Paradigms
- **Guided Setup Wizard**: Linear multi-step flow for mandatory configuration (e.g., setting up an institution profile).
- **Interactive Tooltips / Spotlight**: Contextual coaching marks on high-value features.
- **Empty-State Starter Templates**: Pre-populated sample items (e.g., "Sample Exam Pack") that users can test or edit immediately.

## 2. Reducing Time to First Value (TTFV)
- Defer optional profile questions until after the user completes their first core action.
- Provide sample starter data rather than completely empty, desolate dashboards.
